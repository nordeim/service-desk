## 5. Session-9 process lessons (for the next agent)

1. **Diff the whole `:root`, not just the tokens you know about.** Six sessions of surface probes never noticed that half the token block was a session-1 theme guess — a single CSSOM enumeration (`:root` rule dump → resolve to RGB → diff) catches the entire class in one probe.
2. **Preflight is part of parity.** The v3→v4 migration changed more than utilities — the `button { cursor }` preflight removal is invisible to every class-based probe. Diff the BASE layer rules too, not just the token layer.
3. **Component generation matters even when classes look right.** Our Badge carried the new-gen base under old-gen variant classes; the class-level pins passed while the transition-property silently diverged. Pin computed `transition-property` on interactive surfaces.
4. **The reference's DOM is twMerge output — compare merged strings, not source arrays.** The reference's "two different badge bases" resolved into one base + variant dedupe once read as cn() output.
5. **Shared defects are parity too.** The `transition-argin,opacity]` mangling and the sign-out focus quirk live in BOTH sites — "fixing" them unilaterally is divergence. Verify the reference shares a bug before fixing it (and document either way).
6. **Detached-element probes beat locator gymnastics** for at-rest computed values (the bare-button cursor, the token resolution) — append, read, remove; no traversal races.
